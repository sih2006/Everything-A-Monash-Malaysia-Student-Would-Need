# Design references (awesome-design-md)

The library lives in `.claude/references/awesome-design-md/<brand>/DESIGN.md`. Each file describes one brand's visual language: colour, typography, spacing, components, motion and tone.

## How to use

1. List the brands with `ls .claude/references/awesome-design-md`. Read only the 2 to 4 files relevant to the direction being explored. Each file is roughly 30 KB, so never load the whole library.
2. Treat them as inspiration, not templates. Pull out principles (for example "dense, monochrome, one accent colour, springy motion") and record in the design brief which reference inspired which decision.
3. Never copy brand assets, logos, names or proprietary fonts into the app. The project's own DESIGN.md must describe an original system.
4. The user's own art (the mascots drawn by their artist friend) outranks any reference. If a reference clashes with the mascots, the reference loses.

Source, commit and licence are recorded in `.claude/skills/SOURCES.md`.
